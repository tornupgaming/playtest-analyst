# Hackathon API credits

Credits offered to accepted participants of the Meta Global AI Developer Hackathon (26 Oct – 4 Nov 2026). The Credit Terms PDF is linked from the Official Rules on the event's `/details` page through a signed fbcdn URL that expires on 28 Oct 2026, so a copy is kept in `docs/sources/`.

## Meta Model API credits

| Term | Value | Source |
|---|---|---|
| Amount | USD $150 of promotional Meta Model API credit | [credit terms §3.1](../sources/meta-hackathon-credit-terms.txt) |
| Limit | One claim per participant, one grant per Account; each team member claims for their own Account | [credit terms §3.2](../sources/meta-hackathon-credit-terms.txt) |
| How to claim | Claim Form sent to accepted participants: name, application email, the Account's Team ID | [credit terms §2.1](../sources/meta-hackathon-credit-terms.txt) |
| Claim deadline | 4 Nov 2026, 9:00 PM ET | [credit terms §2.2](../sources/meta-hackathon-credit-terms.txt) |
| Time to apply | "Reasonable efforts" within 2 business days of a valid claim; applied in batches | [credit terms §3.4](../sources/meta-hackathon-credit-terms.txt) |
| Expiry | "Do not expire" once applied; forfeited if the Account is terminated | [credit terms §3.5, §4.2](../sources/meta-hackathon-credit-terms.txt) |
| After credits run out | Usage is charged at standard pricing to the payment method on the Account; the user must watch usage | [credit terms §3.6](../sources/meta-hackathon-credit-terms.txt) |
| Payment method | Every Model API account needs a valid payment method on file before the Services can be used | [credit terms §1.2](../sources/meta-hackathon-credit-terms.txt) |
| Scope | Any use permitted by the API Terms and AUP, including use outside the hackathon | [credit terms §3.3](../sources/meta-hackathon-credit-terms.txt) |
| Judging | Claiming or spending credits does not affect judging | [credit terms §3.7, §3.8](../sources/meta-hackathon-credit-terms.txt) |

The Official Rules and the Credit Terms disagree on validity:

- Official Rules: credits are "valid for a 10-day development window" ([rules](../sources/meta-hackathon-official-rules-2026-10-25.txt)).
- Credit Terms: once applied, credits "do not expire" ([credit terms §3.5](../sources/meta-hackathon-credit-terms.txt)). The Credit Terms say they govern the credits, and the Official Rules govern participation, judging and prizes.

The Credit Terms number their sections 5, then 6.1–6.5 ([credit terms](../sources/meta-hackathon-credit-terms.pdf)).

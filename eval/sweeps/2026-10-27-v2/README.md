# Sweep 2026-10-27-v2

**What this is.** A sweep runs Muse Wonder several times over the same recorded sessions and scores each report against the answer key, to compare ways of asking. The sessions are **synthetic**: a scripted bot plays the test level, and on the `voice` sessions a computer voice reads think-aloud lines (`novoice` sessions have none). `planted` sessions use the level with six **plants**, problems we built in on purpose; `clean` sessions use the same level with them fixed, so any finding there is a false positive. A **config** (`v0`, `v1`, `v2`…) is one way of asking: a prompt version (the written instructions Muse Wonder gets) plus settings such as the frame rate and which inputs it sees; a `-rep` config repeats another to measure run-to-run noise.

Generated by `playtest sweep`. Scored against `eval/ground_truth.json` with pad 10 s. Recall and precision use strict=category; "recall any" ignores the category, so the gap between them is findings in the right place with the wrong label. Recall counts planted sessions only; "FP clean" counts false positives on clean sessions, which have no plants. Cost, latency and output tokens are per run (latency is the model call only).
